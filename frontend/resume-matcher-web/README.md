AI Resume Matcher – Frontend

Frontend for AI Resume Matcher, an AI-powered web application that analyzes resumes and matches candidates with relevant job opportunities based on skills, experience, and relevance.

This project is ongoing and under active development. The current focus is building a solid, clean, and scalable UI while backend features are being integrated.

Tech Stack

Next.js (App Router)

TypeScript

Tailwind CSS

CSS variables for theming

Current Status

Public landing page implemented

Responsive layout and design system in place

Prepared for authentication and API integration

Planned Features

Resume upload flow

AI match score and recommendations

User authentication

Dashboard and profile pages

Notes

This repository reflects real-world, iterative development. Features and structure may change as the product evolves.
