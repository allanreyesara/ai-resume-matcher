# AI Resume Matcher – Backend

Backend API for **AI Resume Matcher**, responsible for authentication, resume processing, and AI-powered job matching.

Built with a clean architecture approach, focused on scalability, security, and real-world production readiness.

> 🚧 **Work in progress** — under active development.

## Tech Stack
- .NET 8
- ASP.NET Core Web API
- Entity Framework Core
- PostgreSQL (Supabase)
- JWT Authentication

## Current Status
- Project structure and infrastructure in place
- Database configured and connected
- Migrations applied
- Authentication flow in progress (JWT)

## Planned Features
- User authentication and authorization
- Resume upload and parsing
- AI-powered resume-to-job matching
- Match scoring and recommendations
- Secure REST API endpoints

## Notes
This backend is being developed incrementally following real-world practices.
Endpoints, models, and architecture may evolve as features are implemented.
